Section 3(e): Zero-Flag Architecture

Unlike classical CISC or older architectures that rely on condition code registers (NZCV flags), LIMO completely eliminates flags to prevent:

  • Pipeline hazard interlocks between ALU & Branch stages
  • Secondary write ports on status registers
  • Out-of-order instruction scheduling bottlenecks
Conditionals compare registers directly in the execution stage via hlk (ha e lekana - beq) and hft (ha e feta - bgt).
